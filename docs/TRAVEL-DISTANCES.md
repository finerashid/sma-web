# Campus travel distances

road, Parwaliya Sadak, Bhopal**. Public labels round the displayed route to the
nearest kilometre; they are approximate road distances, not straight-line distances.

Do not replace these values with directory estimates for RML's Neelbad campus;
some third-party SMA listings conflate the two institutions. Bus and rail distances
refer to the named terminals, not every station or bus stop in Bhopal. No fixed
travel times are published because traffic changes them.

Data lives in `content/site.ts`, links in `lib/directions.ts`. Recheck the named
routes when the campus access road or Google Maps listing changes.
